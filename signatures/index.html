Coller dans Outlook

  1. Outlook sur le web (outlook.office.com) : roue dentée › Courrier › Composer et répondre › « + Nouvelle signature ». Nommez-la « INOVA », collez (Ctrl+V), enregistrez. Sous « Signatures par défaut », choisissez « INOVA » pour les nouveaux messages et pour les réponses/transferts, puis enregistrez.
  2. Nouvel Outlook pour Windows : Paramètres › Comptes › Signatures, même procédure.
  3. Outlook classique (Windows) : Fichier › Options › Courrier › Signatures › Nouveau, collez dans la zone d'édition, puis choisissez-la dans « Nouveaux messages » et « Réponses/transferts ».
  4. Outlook Mac : Outlook › Paramètres › Signatures › « + », collez, puis choisissez-la par défaut.
  5. Outlook mobile (iPhone/Android) : Paramètres › Signature, collez la version texte.
